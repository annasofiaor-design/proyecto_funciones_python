# Proyecto: funciones de python 

Repositorio creado para la documentación, desarrollo y prueba de 30 funciones fundamentales y avanzadas de Python en un entorno de Jupyter Notebook.

## 📂 Estructura del Cuaderno
El archivo principal (`funciones_de_python.ipynb`) está organizado en tres bloques temáticos con su respectiva teoría y ejemplos prácticos:
* **Bloque 1 (1-10):** Funciones básicas y de entrada/salida (`print`, `len`, `type`, etc.).
* **Bloque 2 (11-20):** Funciones intermedias y de colecciones (`max`, `min`, `list`, `dict`, etc.).
* **Bloque 3 (21-30):** Funciones avanzadas y de utilidad (`chr`, `ord`, `enumerate`, `zip`, etc.).

## 🚀 Entorno de Trabajo
* **Plataforma de desarrollo:** Google Colab.
* **Control de versiones:** Git y GitHub.
